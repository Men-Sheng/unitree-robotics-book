====================================================================
第一步：安装必要工具（如果还没有）
====================================================================

1. 安装 Git
   下载地址：https://git-scm.com/download/win

   或使用命令：
   winget install --id Git.Git -e

2. 安装 GitHub CLI（推荐，但非必须）
   下载地址：https://cli.github.com/

   或使用命令：
   winget install --id GitHub.cli -e

3. 安装完成后，重启 PowerShell 或命令提示符

====================================================================
第二步：打开 PowerShell
====================================================================

1. 按 Win + X，选择"Windows PowerShell"或"终端"
2. 或者右键点击"开始"菜单，选择"Windows PowerShell"

====================================================================
第三步：执行上传（三种方法任选其一）
====================================================================

【方法1：使用自动化脚本（最简单）】
--------------------------------------------------------------------
1. 在 PowerShell 中运行：
   cd D:\project\YU-SHU

2. 运行上传脚本：
   .\上传到GitHub.ps1

3. 按照提示操作即可！

【方法2：使用 GitHub CLI（推荐）】
--------------------------------------------------------------------
1. 切换到项目目录：
   cd D:\project\YU-SHU

2. 配置 Git 用户信息：
   git config --global user.name "你的GitHub用户名"
   git config --global user.email "你的邮箱"

3. 登录 GitHub：
   gh auth login
   （选择 GitHub.com → HTTPS → Yes → Login with browser）

4. 初始化并上传：
   git init
   git add .
   git commit -m "首次提交：全球首本宇树机器人深度拆解书"
   gh repo create unitree-robotics-book --public --source=. --remote=origin --push

【方法3：传统 Git 方式】
--------------------------------------------------------------------
1. 切换到项目目录：
   cd D:\project\YU-SHU

2. 配置 Git 用户信息：
   git config --global user.name "你的GitHub用户名"
   git config --global user.email "你的邮箱"

3. 初始化 Git：
   git init
   git add .
   git commit -m "首次提交：全球首本宇树机器人深度拆解书"

4. 手动在 GitHub 上创建仓库：
   - 访问 https://github.com/new
   - 仓库名：unitree-robotics-book
   - 设为 Public（公开）
   - 不要勾选任何初始化选项
   - 点击"Create repository"

5. 推送到 GitHub：
   git remote add origin https://github.com/你的用户名/unitree-robotics-book.git
   git branch -M main
   git push -u origin main
